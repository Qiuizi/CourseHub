**踩坑记录（环境级，非代码缺陷）**：

1. 本机沙箱设置了 `ELECTRON_RUN_AS_NODE=1`。该变量存在时 `electron.exe` 会退化为普通 Node，
   `require('electron')` 拿到的是 npm 包（一个路径字符串）而非 Electron 内置模块，
   表现为 `TypeError: Cannot read properties of undefined (reading 'requestSingleInstanceLock')`。
   **运行 Electron / E2E 前必须 `unset ELECTRON_RUN_AS_NODE`。**
2. `npm install` 时 esbuild 与 rollup 的 Windows 平台可选依赖（`@esbuild/win32-x64`、
   `@rollup/rollup-win32-x64-msvc`）未被自动安装，且 esbuild 的 postinstall 报 `EBUSY`。
   需手动补装，否则 vite/vitest 完全无法启动。
3. Electron 二进制未随安装下载，需手动执行 `node node_modules/electron/install.js`。
4. Playwright 启动 Electron 必须以**项目根**为应用路径（`package.json` 的 `main` 指向
   `./out/main/index.js`）。若把 `out/` 当应用目录，Electron 找不到入口并以 exit code 1 退出。

### 1.2 审计中发现的高风险事实

1. **雨课堂插件存在无人值守提交链路**：`answer-engine.js:154-157` 中
   `autonomyLevel==='auto'` 时直接批准；且 `balanced`（默认）+ 距截止 ≤25 秒 +
   `autoSubmitTimed`（默认 true）时不询问直接提交。
2. **`isExam` 硬规则在答题链路上不可达**：`answer-engine.js:140` 读取 `opts.isExam`，
   但 `submitWithPolicy` 的两个调用点（`:255`、`:297`）均未传入该参数，
   导致 `risk.js:38-40` 的「考试永不自动作答」分支永不触发。
   `tests/classify.test.ts` 中那条「即使考试只剩 1 分钟依然禁止」的断言只测了纯函数，
   给人虚假安全感。
3. **学习通 README 与代码不符**：README 称「系统 A 只管监控提醒」，
   但 `sign.ts:62-67` 真实 POST 签到并携带伪造坐标。
4. **两插件核心能力均未在真实账号验证**：学习通签到/作业字段映射自认「未在你的账号实测」；
   雨课堂项目自己的记忆文件写明「从未在真实雨课堂页面跑过一次」，
   唯一运行日志 5 条中 3 条 `Failed to fetch`、1 条 HTTP 500，**无任何 `code: 0` 成功响应**。
5. **许可证**：两个插件自研代码**均无许可证声明**（无 LICENSE 文件、package.json 无 license 字段），
   默认保留全部权利。因此本项目**未复制其任何源码**，仅学习接口思路并独立实现。

## 5. 已知限制

1. **平台适配器全部为骨架**。三个平台的 `listCourses`/`listTodaySignIns`/`listVideoTasks`
   均返回空数组并标注 `unverified`。这是刻意的：在没有真实响应样本前，
   写死一套猜测的解析逻辑只会产生「看起来能跑、实际静默失效」的模块
   （这正是雨课堂插件当前的状态）。
2. **`classroom:today-signins` 永远返回 `state: 'unverified'`**，
   不展示任何签到条目，避免把未验证数据呈现为事实。
3. **DeepSeek 未做真实调用验证**。流式解析、取消、超时、错误映射均已实现，
   但 `deepseek-flash` 的实际响应格式未经真实请求确认。
4. **地图用经纬度输入 + 数值预览，未接入 Leaflet 瓦片**。
   原型中的地图选点需要在线瓦片服务，存在可用性与使用政策风险；
   本版本提供等价的坐标输入 + GCJ-02 近似换算 + 距离误差计算。
5. **安装包未做代码签名**。`signAndEditExecutable: true` 只做资源编辑，
   未配置证书，Windows SmartScreen 会提示未知发布者。
6. **应用无自动更新**，`publish: null`。
7. **单实例锁依赖 `app.requestSingleInstanceLock()`**，
   若同用户多开，第二个进程会立即退出。
