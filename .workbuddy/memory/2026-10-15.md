### 环境坑（下次直接照做）

1. **`ELECTRON_RUN_AS_NODE=1` 是本机沙箱默认设的** → electron.exe 退化为普通 Node，
   `require('electron')` 拿到 npm 包（路径字符串）→ 报
   `Cannot read properties of undefined (reading 'requestSingleInstanceLock')`。
   **跑 Electron / E2E 前必须 `unset ELECTRON_RUN_AS_NODE`**
2. `npm install` 不装 esbuild / rollup 的 Windows 平台可选依赖，且 esbuild postinstall 报 EBUSY。
   需手动补 `@esbuild/win32-x64` 与 `@rollup/rollup-win32-x64-msvc`，否则 vite/vitest 起不来
3. Electron 二进制不随安装下载，需 `node node_modules/electron/install.js`
4. Playwright 启动 Electron **必须以项目根为应用路径**；传 `out/` 会 exit code 1
5. `@vitejs/plugin-react@6` 要求 vite ^8，与 vite 7 冲突（ERESOLVE）→ 锁 5.2.0
6. `will-download` 是 **Session** 事件，不是 webContents 事件
7. electron-builder 无 git 仓库时在 updateInfo 阶段崩（`computeChannelNames` 读 null.channel）
   → `publish: null` + package.json 补 repository
8. 隐藏窗口里 `canvas.captureStream() + MediaRecorder` 不产生媒体流（readyState=0）；
   测试视频改用 ffmpeg 生成的真实 MP4
9. 被 kill 的 git 进程会留 `.git/index.lock`，确认无 git 进程后删掉即可

### 截图方法学（关键教训，别再踩）
- Playwright `win.screenshot()` **只截 renderer web 内容，不含原生 WebContentsView**
- Electron `win.capturePage()` 截的是窗口 web contents，**同样不含**
- 两者都会让人误判「平台网页/视频/地图没渲染」，然后去做错误的"修复"
- **唯一可靠：PowerShell + .NET `CopyFromScreen` 做 OS 级整屏捕获**
  → `tests/e2e/capture-screen.mjs`，产物 `docs/screenshots/screen-*.png`

### v0.3 修掉的 4 个真实缺陷
1. **平台视图从未创建** → 切场景不触发 `platform.open`，`deps.browsers` 为空，视频/浏览场景全白。
   诊断输出 `browsers: []` 才定位到。修法：挂载时打开默认平台 + 切场景 `ensureOpen`。
2. **平台视图泄漏到其它场景** → WebContentsView 不受 React z-index 约束，切到定位测试时
   仍带旧 bounds 浮在上面（OS 截图里 geo 场景出现视频 fixture）。
   修法：`browser:set-visible` + `geo-test:set-active` 按场景控制，并加 E2E 回归测试。
3. **播放器从不观测** → 设了 `activeTaskId` 但没调 `video.observe`。
4. **地图瓦片全灰** → CSP `img-src 'self' data:` 挡掉 OSM 瓦片。放行后正常。
